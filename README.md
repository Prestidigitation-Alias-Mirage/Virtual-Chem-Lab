# Virtual-Chem-Lab

🧪 Virtual Chemistry Lab

A walk-in virtual chemistry laboratory where you can pick up equipment, handle chemicals, perform experiments, observe reactions, and occasionally blow the entire thing up. 💥

Built as a safe environment for exploring chemistry without the real-world consequences of getting an experiment spectacularly wrong.

🔬 What Is It?

The Virtual Chemistry Lab is an interactive VR chemistry sandbox designed to make experiments feel like an actual laboratory.

Instead of simply selecting an experiment from a menu, you can walk into the lab and interact with it yourself:

🧪 Pick up and manipulate lab equipment

⚗️ Measure, mix, pour, heat, and transfer substances

🔥 Perform chemical reactions

🌈 Observe colour changes and other visible reaction effects

💨 See gas production and other reaction phenomena

🧬 Experiment with different combinations of chemicals

📋 Observe and learn from the results

💥 Make mistakes and see what happens

And yes...

I've already exploded the lab twice. =_=

Fortunately, it's virtual.

🛡️ Chemistry Without the Real-World Risk

One of the main goals of the project is to provide a safe environment for experimentation.

Chemistry experiments can involve hazards such as heat, corrosive substances, toxic materials, pressure, or unexpected reactions. In a virtual environment, those consequences can be simulated without exposing the user or their surroundings to the physical hazards.

If you accidentally create an extremely questionable reaction:

💥 BOOM

...you can reset the lab and try again.

No broken glass.
No chemical spills.
No damaged equipment.

Just a slightly concerned virtual lab assistant.

🧪 Features

🖐️ Fully Interactive Laboratory

The lab is designed around physical interaction rather than menus.

You can:

Pick up beakers, test tubes, flasks, and other equipment

Move objects around the laboratory

Pour substances between containers

Combine reagents

Heat substances

Perform experiments in different apparatus

Observe changes as they happen

🌈 Visual Reaction Effects

Reactions aren't just represented by text.

Depending on the reaction, the simulation can display phenomena such as:

Colour changes

Precipitate formation

Gas production

Temperature changes

Bubbling/fizzing

Flame/heat effects

Other observable reaction behaviour

💥 Failure Is Part of the Simulation

The laboratory isn't designed to punish experimentation.

If you make a mistake, the simulation can represent the consequences and allow you to reset the environment.

This makes it possible to explore questions like:

"What happens if I mix these?"

without turning the question into:

"What happens if I mix these in my actual bedroom?" 💀

🔄 Reset & Experiment Again

Make a mess?

Break something?

Cause an extremely enthusiastic reaction?

Explode the laboratory for the third time?

Reset and start again.

🎓 Educational Goals

The project aims to make chemistry more interactive, visual, and exploratory.

Rather than only reading:

"A colour change occurs."

you can actually see the colour change happen.

Rather than memorising that two substances react, you can interact with them and observe the resulting phenomena.

The goal is to encourage experimentation while keeping the environment controlled and safe.

⚠️ Important Note

This is a simulation and educational project, not a substitute for appropriate laboratory supervision or real-world chemical safety procedures.

Virtual experimentation is intentionally separated from real-world experimentation: the point is to provide a place where users can explore chemistry without exposing themselves or others to physical hazards.
